**Question 1**: What is a computer system?
**Response**: A computer system is a set of hardware and software that work together to process inputs, data and produce an output.
**Question 2**: What are some of the parts of a computer system?
**Response**: CPU, RAM, Motherboard, Hard Drives, Power supply, GPU, Keyboard, Mouse, Monitor.
**Question 3**: What is the difference between a compiled language and an intepreted language?
**Response**: A compiled language is translated all at the same time into machine code by a compiler. An interpreted language is translated and ran one line at a time with an interpreter.
**Question 4**: Is C a compiled language?
**Response**: Yes.
**Question 5**: Who invented the C language?
**Response**: Dennis Ritchie.
**Question 6**: How long has C been in use?
**Response**: Around 50 years.
**Question 7**: Is a compiler a translator?
**Response**: Yes, it translates source code that is written at a high level into lower level language.
**Question 8**: Is an assembler a translator?
**Response**: Yes, it translates assembly language into machine language.
**Question 9**: What is the command to list out the contents of a directory on a mac terminal window?
**Response**: ls
**Question 10**: What does the C function atof() do?
**Response**: It converts a string of characters into a float
